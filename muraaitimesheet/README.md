# Muraai Timesheet Project

## Overview
Muraai Timesheet is a project management application designed to help teams manage their projects, tasks, and time logs efficiently. This application provides features similar to Zoho Projects, allowing users to create and manage projects, assign tasks, track time, and visualize project progress through a dashboard.

## Features
- **Project Management**: Create, update, and delete projects. Manage project details and track progress.
- **Task Management**: Assign tasks to team members, update task statuses, and manage task details.
- **Time Logging**: Log time spent on tasks and projects, providing insights into productivity and resource allocation.
- **Dashboard**: A comprehensive dashboard that displays project summaries, key metrics, and overall progress.

## Directory Structure
- `src/components/layout`: Contains layout components for the application structure (headers, footers, sidebars).
- `src/features/dashboard`: Components and services related to displaying project summaries and key metrics.
- `src/features/projects`: Components, services, and types for managing projects.
- `src/features/tasks`: Components, services, and types for managing tasks.
- `src/features/time-logs`: Components, services, and types for logging time against tasks and projects.
- `src/hooks`: Custom hooks for managing state and side effects.
- `src/shared`: Shared types and utility functions.
- `src/electron`: Electron-specific code for the application.

## Installation
To get started with the Muraai Timesheet application, clone the repository and install the dependencies:

```bash
git clone <repository-url>
cd muraaitimesheet
npm install
```

## Usage
To run the application, use the following command:

```bash
npm start
```
